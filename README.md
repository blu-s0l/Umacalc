# Umacalc

Trainee and support card collection manager for Umamusume: Pretty Derby, with a deck
planner, a Team Trials team builder and a resource planner.

Open `index.html` from a web server, or GitHub Pages. Everything you enter stays in your
browser's local storage. Use **Data → Export** to back it up.

Game data is from [GameTora](https://gametora.com/umamusume). To refresh it:

```
py -I tools/build_data.py <empty-download-dir>
```
